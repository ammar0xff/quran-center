# Screen Specifications

Screens grouped by role. Every screen has: loading, empty, error, success states; Arabic RTL; accessibility semantics; defined validation; no placeholder/decorative non-functional controls.

## Authentication (shared)

1. **Splash** — logo, app name, branded indicator, optional static phrase. Initializes Firebase, restores session, resolves role, navigates to login or dashboard. States: normal, slow init, recoverable error (retry), config error. Never infinite spinner.
2. **Welcome & Login** — brand mark, greeting, email field, password field + visibility toggle, sign-in, forgot password, help, privacy/terms. No public role selector. Validation: trimmed email, basic format, Arabic messages. Loading feedback, disable resubmit in flight, localized errors, navigate by authoritative role.
3. **Forgot Password** — title, explanation, email input, send reset link, back to login, loading/success. Privacy-preserving confirmation, no account-existence leakage.
4. **Account Pending / Suspended** — status icon, explanation, contact admin action, retry authorization, sign out. No privileged data.

## Teacher

5. **Teacher Home Dashboard** — greeting + name, Arabic date, notification, profile, offline/sync indicator. Welcome section + "Open Today's Teaching Session". Summary cards: assigned students, today's circles, absent today, assessments today, overdue follow-ups (each opens filtered list). Today's schedule (circle, time, mode, student count, status, open session/view circle). Quick actions: record attendance, record memorization, open students, review follow-ups. Follow-up section (overdue tasks, repeated absences, revision due, incomplete records) with student, reason, date, action. Recent activity. States: new teacher/no assignments, no classes today, no follow-ups, loading, offline cached, partial error.
6. **Teacher Circles List** — "My Circles", search, filter, optional view toggle. Circle card: name, level, schedule, student count, session status, mode, next session, open circle. Filters: active, archived (if authorized), day, level, status. Empty state: no circles assigned, contact director. Teachers cannot create/reassign circles unless authorized.
7. **Circle Details** — header: name, status, schedule summary, back, contextual menu. Tabs: Overview, Students, Schedule, Session History. Overview: teacher, student count, capacity, upcoming session, recent summaries, notes. Students tab: search, filter by enrollment, name/avatar, level, latest assessment, attendance, follow-up indicator, open profile. Schedule tab: weekly schedule, time, mode, notes. Session History: date, status, attendance completion, assessment count, open summary. Primary action: start/open next session.
8. **Student Roster** — title, circle selector (if multiple), search, filters. Row/card: name, avatar/initials, level, latest memorization, attendance summary, outstanding tasks, account mode indicator, open profile. Filters: all, needs assessment, revision overdue, repeated absences, inactive (if authorized). Quick actions: open student, record assessment, view attendance. No destructive actions on roster card. Pagination/incremental loading.
9. **Student Educational Profile** — header: name, enrollment status, circle, account mode, more actions, back. Summary: name, photo, preferred name, enrollment date, teacher, circle, level, accessibility preferences (only if needed). Indicators: recent attendance, recent assessment, active tasks, revision due, last session. Tabs: Overview, Memorization, Learning Plan, Attendance, Educational Notes. Overview: goals, latest assessment, upcoming assignments, follow-up alerts, activity timeline. Memorization: filter by date/surah/type, list history with surah/ayah range, criteria, notes per permissions, open details. Learning Plan: targets, completed, upcoming, overdue, dates, details. Attendance: calendar/list, present/absent/late/excused counts, date filters, session details. Educational Notes: add note, view permitted notes, edit when authorized, date+author, private vs student-visible distinction. Actions: record assessment, assign task, add note, view attendance, open plan. Never assumes Firebase account.
10. **Teaching Session** — header: circle, date, time, status, student count, attendance completion, assessment completion, save/sync indicator. States: scheduled, in_progress, completed, cancelled (valid transitions enforced). Roster: name, attendance status, assessment status, latest result, quick attendance control, record assessment, open profile. Attendance statuses: present, absent, late, excused (color not sole indicator). Bulk: mark all present, mark selected present, mark absent/excused individually, undo local change before submit. Bulk shows scope, confirms before overwrite. Footer: unsaved changes, pending sync, review session, submit/close. No silent submit of incomplete/conflicting records.
11. **Attendance Entry** — header: session, date, completion progress. List: search, name, current status, status selector, optional note, last updated. Statuses: present/absent/late/excused via segmented selector/compact menu. Validation: one record per student per session, valid session+student assignment, no duplicate submit, authorized corrections, preserve original + audit metadata. Submission: save draft, submit attendance, summary of saved, unresolved conflicts/unsynced ops. Not marked synced until server confirms.
12. **Memorization Assessment** — 7 steps: (1) student+session+date/time+change student; (2) type: new_memorization/recent_revision/long_term_revision/general_recitation; (3) surah selector, start ayah, end ayah, range validation, no fabricated Quran text; (4) criteria: accuracy, tajweed, fluency, pronunciation, independence (director-configurable required criteria, Arabic labels); (5) mistakes: count, category, reference, correction/observation, follow-up flag (fast, advanced optional); (6) result: overall, strengths, improvements, private note, student-visible feedback, next assignment, next review date; (7) save: save assessment, save and add next, cancel. Unsaved-navigate confirmation. Post-save: persist, update history, update task status per business rules only, offer next task, return to profile/session. Never auto-mark mastery on submission.
13. **Learning Plan** — header: student, status, date range, edit if authorized. Summary: objective, new memorization target, revision target, frequency, start, target date, teacher. Task list: type, surah/ayah, due date, status, last assessment, notes, open task. Statuses: upcoming, in_progress, practice_reported, submitted_for_review, completed, needs_review, overdue, cancelled (documented state machine). Actions: create, edit, reorder, mark teacher-verified completed, return for review, cancel with reason. Self-reported ≠ verified.
14. **Task Creation/Editing** — fields: student, type, surah, start ayah, end ayah, assigned date, due date, priority, instructions, review requirements, reminder. Validation: required fields, valid ayah range, due date rules, student in teacher scope, no accidental duplicates. Actions: save, save and create another, cancel. Shows updated plan after save.
15. **Teacher Follow-Up** — sections: overdue tasks, revision due, repeated absence, missing assessment, needs review. Item: student, circle, reason, date, severity/priority (documented rules), open student, resolve/snooze. Explains why item appears. No arbitrary "failing" labels.
16. **Teacher Notifications** — new assignments, schedule changes, announcements, alerts. Item: title, message, timestamp, read/unread, related entity. Actions: mark read, mark all read, open related record, empty state. No sensitive student details in payloads.
17. **Teacher Profile & Settings** — name, account info, center, circles, status. Actions: edit permitted fields, change password (secure flow), notification prefs, theme, language, sync status, help, privacy, sign out. Cannot change own role/permissions.

## Student

18. **Student Dashboard** — greeting, name, notification, avatar/initials. Main learning card: today's primary assignment, type, surah/ayah, due date, status, open task. Today's tasks: new memorization, recent revision, long-term revision, other work. Upcoming class: circle, teacher (if permitted), date/time, mode, view schedule. Progress: completed tasks, plan progress, revision consistency, recent teacher-verified results. Latest feedback: student-visible feedback + date + link to assessment. Motivation: respectful, noncompetitive, real activity only. No unsupported mastery claims.
19. **My Tasks** — title, period selector, search/filters. Filters: all, today, upcoming, in progress, needs review, completed. Task card: type, surah/ayah, due date, status, instruction summary, open task. Empty states distinguish: no tasks, all completed, no results for filter, data unavailable (connectivity).
20. **Task Details** — title, type, assigned teacher, surah/ayah, assignment date, due date, instructions, status, related feedback, previous assessment (if permitted). Student actions: mark practice completed (أتممت التدريب), optional reflection, submit for review (if enabled), view related revisions. Self-reported stored as such. UI communicates teacher verification may still be required. No editing official scores/attendance.
21. **My Progress** — summary: current plan, completed, pending, recent verified results, attendance. Charts (where useful): completed over time, attendance over period, assessment trends on configured scale. Filters: date range, task type, surah. History entries: date, type, passage, verified result, feedback. Distinguish verified vs self-reported.
22. **Student Attendance** — summary: present, absent, late, excused for period. Session history: date, circle, status, authorized notes. Filters: date, circle. Cannot modify official records. Contact/correction-request only if center enables.
23. **Student Schedule** — upcoming sessions, weekly view, date/time, circle, location/mode, teacher (if authorized), change indicators. Center timezone, no device-local-only reminders.
24. **Teacher Feedback** — title/category, date, related assessment/task, student-visible comment, next steps. Private notes never shown. Empty/loading/error states.
25. **Student Notifications** — class reminders, assignments, feedback, announcements. Actions: mark read, open related, mark all read. Deep links only after authorization validation.
26. **Student Profile** — name, profile info, teacher, circle, current plan, notification prefs, account status. Edits only permitted fields. Actions: edit profile, notification settings, privacy, sign out. No internal admin metadata.

## Director

27. **Director Dashboard** — greeting, center name, date, notification, profile/settings. KPI cards: active students, active teachers, active circles, sessions today, attendance rate, students needing follow-up, pending enrollment (if enabled). Each opens filtered detail. Today's operational summary: scheduled, completed, in progress, not started, incomplete records. Attendance overview chart/summary (denominator + excused treatment defined). Educational follow-up: overdue plans, repeated absences, pending assessments, incomplete circles. Teacher activity: sessions recorded, attendance submitted, assessments completed, pending admin items (not quality measure). Quick actions: add student, add teacher, create circle, manage schedule, open attendance, generate report, create announcement. Filters: date range, circle, teacher, enrollment status (preserved on drill-down).
28. **Student Management List** — title, add student, search, filter, sort. Search by name/student ID/authorized identifiers (not require email/phone). Filters: active/pending/archived, circle, teacher, has login/no login, suspended access, follow-up required. List: name, ID, circle, teacher, status, account status, latest attendance/assessment, actions menu. Actions: open profile, edit, assign circle, change teacher, enable/manage access, archive/reinstate. Confirmation for destructive/high-impact.
29. **Add Student** — stepper form. Section A basic: full name (required), preferred name, DOB (optional), contact (optional), image (optional), admin notes (staff). Section B educational: level, circle, teacher, enrollment date, status, initial plan (optional). Section C digital access: no login (default) or create login — required account info only, secure provisioning, verify linking, no fake credentials, no temp passwords in logs. Section D review summary. Actions: save student, save and add another, cancel. After: name, ID, circle, teacher, account mode, next actions (open profile, create plan, add another). No duplicates on retry.
30. **Director Student Profile** — header: name, ID, status, account access, more actions. Summary: circle, teacher, enrollment date, latest assessment, attendance, active tasks, follow-ups. Tabs: Overview, Educational History, Learning Plans, Attendance, Enrollment, Account Access, Audit History (if authorized). Overview: progress, upcoming, recent activity, admin alerts. History: memorization, revision, assessments, notes per permissions. Plans: current, previous, task history, completion. Attendance: history, filters, corrections with audit. Enrollment: dates, circle/teacher history, transfers, withdrawal/archive. Account Access: login exists?, status, linked user ID (staff), provisioning status, activate/suspend. No auth secrets. Actions: edit, assign circle, change teacher, create plan, review assessments, enable access, suspend access, archive.
31. **Teacher Management** — list: name, status, assigned circles, student count, recent activity, search/filters. Filters: active/suspended/archived, has circles/no assignments. Actions: add teacher, open profile, edit, assign circles, reassign students, suspend, reactivate. Teacher profile: info, circles, students, schedule, activity, status, history. No auth secrets.
32. **Add/Edit Teacher** — full name, contact, image, professional notes, assigned circles, provisioning status. New teacher: authorized backend account creation, teacher role, center association, secure activation, verify access. Teacher cannot self-grant director.
33. **Circle Management** — list: name, level, teacher, student count, capacity, weekly schedule, status. Filters: active/archived, teacher, level, day, capacity. Actions: create, open details, edit, manage students, manage schedule, archive. No deletion that destroys history.
34. **Create/Edit Circle** — name, description, level, teacher, capacity, location/mode, weekly schedule, session duration, status, admin notes. Validation: name required, capacity valid, schedule conflicts detected, teacher authorized+active, warn at capacity, prevent overlapping assignments. Actions: save, save and add students, cancel.
35. **Circle Details & Student Assignment** — summary, teacher, schedule, capacity, students, enrollment history. Add students: search profiles, filter unassigned/eligible, multi-select, preview roster, confirm. Remove/transfer: explain impact, preserve history, effective date, confirm, atomic updates. No deletion of student records on leaving.
36. **Schedule Management** — views: daily, weekly, list. Entry: circle, teacher, date, start/end time, mode, status. Filters: teacher, circle, day, date range, status. Actions: create session, edit, reschedule, cancel, open details. Validation: start<end, teacher conflicts, circle conflicts, operating hours, conflicts before save, cancellation reason, preserve history. Session detail: metadata, attendance status, assessment completion, roster, change history.
37. **Attendance Administration** — header: date selector, circle filter, teacher filter, status filter. Summary: total eligible, present, absent, late, excused, missing (missing ≠ absence without policy). List: student, circle, date, teacher, status, last update, correction history. Actions: open student, open session, correct attendance, export. Correction: original status, new status, reason, actor, preserve original in audit, apply securely, refresh summaries.
38. **Educational Supervision** — sections: overdue tasks, repeated absences, needs revision, incomplete assessments, incomplete circles, plans needing review. Filters: period, circle, teacher, student, category. Detail: reason, supporting dates/records, trend, responsible teacher, suggested action. No automated judgments on commitment/intelligence/ability.
39. **Reports** — student (enrollment, attendance, memorization, revision, plan completion, assessment trends), teacher (students, sessions, attendance completion, assessment activity, follow-ups), circle (enrollment, capacity, attendance, sessions, memorization), operational (daily session summary, attendance, missing records, pending admin). Filters: date range, student, teacher, circle, status, type. Export: CSV for authorized datasets; PDF when supported. RTL + Arabic in exports. No unauthorized exports, no logging of exported data. Show status + filters used.
40. **Announcements** — list: title, audience, status, scheduled time, author, date. Create: title, message, audience, circles/users, immediate/scheduled, expiration, preview. Audiences: all users, teachers, students with accounts, selected circles, selected users. Accountless students not assumed to receive electronic notifications. Actions: save draft, preview, publish, schedule, cancel scheduled, archive. Validate permissions, audit log.
41. **Account Administration** — user list: name, role, center, status, last sign-in (if permitted), provisioning. Filters: role, active/suspended, provisioning pending, access enabled/disabled. Actions: open profile, activate, suspend, revoke, reissue activation, change assignments. Role changes need elevated authorization + reauth. No client-side privileged role creation.
42. **Center Settings** — sections: general (name, logo, contact, timezone, locale, date/number format), educational (criteria, scales, attendance statuses, default duration, task defaults, reminders), permissions (who can correct attendance/edit assessments/view private notes/export), notifications, data management (export, retention, audit, integrity), branding (logo, theme, light/dark default). Confirmation before workflow-affecting changes. Cannot override backend security rules.
43. **Director Profile & Settings** — profile, notification prefs, theme, account security, session management, help, privacy, sign out. Securely provisioned, not self-creatable via public registration.
