# Quran Memorization Center Management System

Premium, Arabic-first Flutter + Firebase management system for a Quran memorization center (دار تحفيظ قرآن). Supports teachers, students, and directors in a single installed application.

## Tech stack (target versions — verify after Flutter SDK setup)
- Flutter stable, Dart null safety
- Riverpod, go_router
- Firebase Auth, Firestore, Cloud Messaging, App Check, Crashlytics
- Drift + SQLite (offline outbox)
- Arabic localization (intl), IBM Plex Sans Arabic

## Status
Phase 1 complete: repository skeleton, architecture, data model, security, screen specs, workflows, and testing docs. Flutter SDK not yet installed in this environment — see `docs/` and `SETUP.md` (to be created) for bootstrap instructions.
